# SmartAccess Web

Front-end only prototype of the SmartAccess operator dashboard. There is no backend yet. A mock API (MSW) serves realistic data from `src/mocks/data`.

## Stack

Vite · React 19 · TypeScript · Tailwind CSS v4 · shadcn/ui · React Router · Recharts · Lucide · MSW · Vitest · oxlint · Prettier

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server at http://localhost:5173 |
| `npm run build` | Type-check and build to `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm test` | Run tests (Vitest, watch mode) |
| `npm run lint` | Lint with oxlint |
| `npm run format` | Format with Prettier |

## Structure

```
src/
  app/          App providers and route table
  layouts/      App shell (sidebar + content)
  pages/        One file per route (Dashboard, Buildings, Access Log, Policies, Alerts)
  components/   Shared components; ui/ is generated by shadcn (don't hand-edit heavily)
  api/          Typed fetch client; the only place the UI talks to "the backend"
  mocks/        MSW handlers + mock data (browser and test)
  types/        Domain types, which are the future contract with the backend
  test/         Test setup and smoke tests
```

Add a shadcn component: `npx shadcn@latest add <name>`

## Moving to a real backend

1. Set `VITE_API_URL` to the backend URL and `VITE_USE_MOCKS=false` (see `.env.example`).
2. Keep `src/types` in sync with the API contract.
3. Add TanStack Query for caching and refetching once real data is in play.
